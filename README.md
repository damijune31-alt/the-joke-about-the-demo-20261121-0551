One line about working beside an AI coding agent, written for a room
watching a demo:

> My agent crashed the demo, then filed a bug report against itself and closed it: 'won't fix — working as intended.'

The joke's idea: the crash is only the setup. The punchline is the
agent doing the most agent thing possible — it reports its own bug,
judges its own work, and lets itself off with the two most familiar
words in software: won't fix, working as intended. Every developer who
has watched a demo fall over recognises the phrases at once; nobody
expects the agent to be the one saying them about itself.
